Fabriquer tes propres outils

Depuis la première séance, tu utilises des outils que d'autres ont écrits : print, input, len, round. Aujourd'hui, tu fabriques les tiens.

1

Donner un nom à un bout de programme

15 minutes · def

def veut dire « définis ». Tu donnes un nom à un bloc de code, et ce bloc ne s'exécute pas tout de suite : il attend qu'on l'appelle.

Le code du prof
À toi de taper

Deux temps bien séparés : définir (le bloc def, qui ne fait rien tout seul) et appeler (dire_bonjour(), avec les parenthèses, qui déclenche l'exécution).

🐛 L'oubli garanti

Écris dire_bonjour sans les parenthèses. Aucune erreur… et rien ne s'affiche.

Sans parenthèses, tu désignes l'outil. Avec parenthèses, tu t'en sers. C'est exactement la différence entre montrer un marteau et taper avec.

2

Un outil réglable

15 minutes · les paramètres

Un outil qui fait toujours exactement la même chose sert rarement. Ce qui est entre les parenthèses du def, ce sont les réglages - comme le 100 dans forward(100) à la toute première séance.

Le code du prof
À toi de taper

Une seule définition, trois usages différents. C'est ça, un outil.

🎙️ Le mot juste

Dans le def, prenom est une case vide qui attend qu'on la remplisse. Au moment de l'appel, "Awa" vient s'y installer, le temps de l'exécution seulement.

Analogie : def, c'est le formulaire vierge. L'appel, c'est le formulaire rempli.

la promesse de la séance 0

3

Un outil qui rend un résultat

15 minutes · return

Jusqu'ici tes outils affichaient. Souvent, on préfère qu'ils rendent une valeur, pour pouvoir s'en resservir. C'est ce que fait return.

Le code du prof
À toi de taper
💡 print ou return ?

print montre à l'utilisateur. La valeur part à l'écran et disparaît, on ne peut plus rien en faire.

return rend au programme. On peut la ranger dans une boîte, la recalculer, la comparer - comme m1 + m2 ci-dessus.

Règle simple : un outil qui calcule doit return. Un outil qui affiche peut print. Mélanger les deux, c'est se limiter.

🐛 À tester

Remplace return par print dans la fonction, puis essaie de calculer (m1 + m2) / 2.
TypeError: unsupported operand type(s) for +: 'NoneType' and 'NoneType'

Une fonction sans return ne rend rien du tout - littéralement « rien », qui s'appelle None en Python. Et on ne peut pas additionner deux riens.
