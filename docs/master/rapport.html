Ce que contient ce code

et ce qu'il ne contient pas

Il contient : le nombre de programmes écrits par séance, les exercices terminés, la liste des lignes qui ont demandé plusieurs essais ou dont la réponse a dû être affichée, et l'avancement de la liste de contrôle du projet final.

Il ne contient pas : le code écrit par l'étudiant, son nom, ni aucune donnée personnelle.

🌍 Rien ne transite par un serveur

Le site est un ensemble de fichiers statiques : il n'envoie aucune donnée nulle part. Le code est fabriqué dans le navigateur de l'étudiant, et il ne voyage que parce qu'il te l'envoie lui-même. Cette page le décode dans ton navigateur, hors ligne si tu veux.
